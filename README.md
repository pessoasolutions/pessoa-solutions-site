# PESSOA SOLUTIONS

Site vitrine de PESSOA SOLUTIONS, en ligne sur https://pessoa-solutions.fr

## Contenu

- `index.html` : le site complet, une seule page (structure, styles et scripts inclus)
- `assets/` : logos et polices de la marque
- `_headers` : mise en cache des assets par Netlify
- `robots.txt`, `sitemap.xml` : referencement

## Fonctionnement

Site statique, sans etape de build ni dependance externe. Chaque commit sur `main`
declenche automatiquement une mise en ligne sur Netlify.

## Identite

Blanc pur `#FFFFFF`, bleu marine `#0A1F44`, bleu petrole `#0B5A75`, doré `#B08D57`.
Mode nuit : fond `#070C15`, surfaces `#0D1725`, accent `#4FA9C6`.
Polices : Amiri pour les titres, Lato pour le texte, reprises du logo.
